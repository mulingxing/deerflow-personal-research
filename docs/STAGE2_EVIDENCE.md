# 第二阶段：报告来源与证据提示

## 使用时会看到什么

研究报告完成后，页面下方显示“证据检查”和“检索到的来源”。这里的来源直接来自研究工具返回的数据，不依赖模型自己编写的参考文献。上传资料可显示 PDF 页码或 Word、Markdown 的章节位置；网页来源可打开原网页。

证据检查会统计正文段落中有多少段标注了有效来源编号，并提示报告中不在检索结果里的链接、越界的引用编号。这个数字叫**引用覆盖率**：它只表示段落有没有标注已知来源，**不表示来源内容一定支持该结论，也不等于事实真实性评分**。读者仍应打开来源或回看上传资料核对重要结论。

## 实现思路

研究阶段从网页搜索、网页阅读或个人资料检索结果中收集来源。报告生成阶段把有限数量、有限长度的来源片段及其编号交给报告模型，要求它在事实性段落附近使用编号，并在证据不足时说明限制。网页或上传文件中的文字被当作数据，不能作为系统指令。前端另外根据真实来源数据检查报告中的编号和链接，显示可核对的来源面板。

报告质量评估中的“引用数”和“来源数”会识别正文 `[[n]](#ref-n)` 编号；这些数量指标同样不是语义核验。

相关代码：`src/citations/report_sources.py` 负责整理证据；`src/graph/nodes.py` 的 reporter 节点提供证据给模型；`web/src/core/evidence/audit.ts` 检查报告引用格式；`web/src/app/chat/components/research-report-block.tsx` 展示结果。
