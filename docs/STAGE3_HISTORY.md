# 第三阶段：聊天历史

聊天页面左上角的“历史记录”可新建会话、打开旧会话和删除会话。研究过程中的提问、报告、引用、研究活动，以及当时选择的资料和“仅联网／仅我的资料／资料 + 联网”模式，会作为会话快照保存在本机。新会话发送第一条消息后才会出现在列表中。删除会话会删除对应的聊天快照，不会删除已上传的资料。

打开旧会话后可以继续提问。每次新研究都会创建独立的运行 ID，避免 LangGraph 把上一轮消息再次当作本轮消息；前端只把最近最多 12 条、总计最多 12000 字的已完成问答作为上下文传入。不完整的报告、工具过程和计划确认反馈不会作为追问上下文。因此续聊能参考最近内容，但不是无限长、逐字完整的对话记忆。

刷新页面或断网会中断当前的流式研究。历史里会保留已生成的文字，并标为“需要重试”；半截报告不会被当作完整报告供后续追问或生成 PPT。请重新提问以启动新一轮研究。若后端重启，正在运行及等待计划确认的会话也会标为需要重试；它们不能继续原来的内存运行。若浏览器异常退出而后端仍在运行，服务器记录可能暂时停留在“运行中”；重启后端会将其标为“需要重试”。

快照保存在项目根目录的 `.runtime/conversations.sqlite3`，单条快照上限为 16 MB。流式内容约每 1.5 秒保存一次，正常结束时会再保存一次，因此意外断电前的最后少量文字可能未入库。该功能面向本机单用户使用；另一标签页正在研究同一会话时，本页只读显示其快照，可稍后刷新历史列表或点击历史项重新加载。确认原任务已经停止后，也可在历史栏手动将其标为中断，再重新提问。两个标签页先后编辑同一会话时，较旧标签页的保存会收到冲突提示，不会静默覆盖较新版本。遇到冲突，请刷新网页查看数据库中的最新记录；两个标签页的内容目前不会自动合并。

当前历史 API 没有登录验证或按用户隔离。只在本机可信环境使用；若将后端开放给局域网、企业同事或公网，任何能访问 API 的人都可能读取或删除历史记录。多人部署前需要先加身份验证和数据权限隔离。
